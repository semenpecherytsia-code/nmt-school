# Записи занять + Календар (демо)

Окремий сайт у стилі matanschool.com: три розділи.

1. **Записи занять** — групи по місяцях (+ власні групи, напр. «Додаткові уроки»), пошук, «Розгорнути все».
2. **Перегляд запису** — відео, частини запису, вкладки «Презентація» і «Конспект», кнопка **«Зберегти офлайн»** (відео зберігається в браузері, дивитися можна без інтернету), прогрес перегляду.
3. **Календар** — вигляд «Календар» і «Список» з кнопками «Запис». За замовчуванням уроки в середу і неділю.

Адмінка: `…/zapysy/#/admin` (пошта + пароль). Редагується все: уроки, дати, час, відео, презентації, конспекти, групи, дні розкладу, назви.

## Підключення хмари
Один раз виконати SQL у Supabase (SQL Editor → Run). Приватний файл з адміном лежить не в репозиторії.
`supabase.sql` тут — та сама схема без адмінів.

## Як вставити в основний сайт
- Посиланням: `https://<сайт>/zapysy/` або одразу на розділ: `#/zapysy`, `#/calendar`, `#/offline`.
- Вбудувати в сторінку (без верхнього меню):
```html
<iframe src="https://semenpecherytsia-code.github.io/nmt-school/zapysy/?embed=1#/calendar"
        style="width:100%;height:900px;border:0" allow="fullscreen"></iframe>
```
- Або просто скопіювати папку `zapysy/` на свій хостинг поруч із сайтом — усе в одному `index.html` (+ `sw.js`, `media/`).

Відео для офлайн-збереження — пряме посилання на файл `.mp4` (наприклад, Supabase Storage або той самий хостинг). YouTube працює тільки онлайн.
